# sanad-collector

الصفحة الثابتة لتطبيق **«سند: الموظف الجامع»** (نموذج إدخال طلبات الأيتام دون إنترنت). تُنشر عبر GitHub Pages لتُثبَّت على iPhone وأي متصفح.

- **لا بيانات هنا ولا مفاتيح ولا خادم.** ملفات HTML وCSS وJavaScript فقط.
- الطلبات التي يُدخلها الموظف تبقى **على هاتفه مشفَّرة**، ولا تُرسل إلى أي مكان إلا بملف مشفَّر يرحّله بنفسه إلى حاسوب الجمعية.
- الملفات تُولَّد تلقائياً من مشروع «سند» (مستودع خاص). لا تُعدَّل يدوياً هنا.
